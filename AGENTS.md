- **Water Tiles & Plant Spawning:** Water tiles are represented by `'obs'` in `mapData`. Shore plants like cattails and pampas grass use distance-based checks (scanning a 2-tile radius for `'obs'` tiles) to drastically increase their procedural generation probability near water edges.
- **Dynamic Entities & Day/Night Overrides:** Ambient creatures (butterflies, fireflies, birds) are controlled via global emitters (e.g., `window.butterflyEmitter`, `window.birdEmitter`) that use offscreen canvas sprite generation. They follow strict day/night overrides in the weather loop: butterflies and birds are hidden at night (`if (isNight) targetButterflies = 0; targetBirds = 0;`), and fireflies are hidden during the day.
- **BirdManager:** Dynamic ambient birds are handled by the `BirdManager` (`window.birdEmitter`) using offscreen canvas sprite generation (`bird_particles`). They use state-machine AI to fly rapidly, land on trees and the ground, and interact/play with other birds of the same species.
- **2D Lighting:** Dynamic 2D lighting during the night cycle uses a `Phaser.GameObjects.RenderTexture` (`dayNightOverlay`). Illumination is created dynamically by erasing holes using `dayNightOverlay.erase()` with a radial gradient. When mocked in tests, this overlay must include an `erase()` method.
- **Playwright Testing:** Tests are run via `npx playwright test`. A local web server must be running on port 3000 (`python3 -m http.server 3000 &`). If `Math.random` is mocked via `page.evaluate`, it must be synchronously restored immediately after invoking game logic to prevent infinite loops (`SBOX_FATAL_MEMORY_EXCEEDED`).
- **Co-op Mode Testing:** Toggle co-op mode by invoking `window.handleCoopToggle()` or explicitly using `window.enableCoop(scene)` and `window.disableCoop(scene)`.
- **Canvas SVG Generation:** To utilize detailed SVG icons for in-world items (like furniture), `generateTileTextures` handles `img.onload` to draw the SVG to a canvas. Chromium canvas SVG rendering requires the SVG string to be converted to a Base64 data URI (`btoa()`) and must explicitly include the `xmlns="http://www.w3.org/2000/svg"` attribute.
- **WebGL Reset:** When exiting a game session to the main menu, use `location.reload()` rather than manual state cleanup to fully reset the WebGL context and prevent black screens.
- **Phaser Arcade Physics:** To prevent Phaser Arcade Physics from accumulating massive delta times and causing extreme movement speeds after a browser tab is backgrounded, the Phaser configuration must include `fps: { panicMax: 120 }`.
- **Tone.js Syntax:** When triggering rapid or frequent Tone.js synth sounds (such as footsteps or leaves), pass `undefined` instead of `Tone.now()` to `triggerAttackRelease()` to trigger them immediately and prevent Web Audio Context queue buildup or time divergence crashes.
- **Loading Screen Timeout Mitigation:** To prevent the loading screen from timing out during headless Playwright tests, the `draw()` loop forces `progress = 100` and `targetProgress = 100` immediately once `window.phaserInitComplete` is true and `currentStage >= stages.length`.
- **Deprecated Features:** The game no longer supports the 'item wheel', 'pedometer', 'storage chest tile', main screen player coordinates, or the ability for players to place/delete their home in the world. Ensure UI documentation omits these.
- **State-machine AI:** Entities like birds use state-machines (`wandering`, `seeking_bird`, `landing_tree`, `playing`) to manage autonomous interactions with their environment and each other.
