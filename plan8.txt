   Add `treeShadow.setScale(2.5, 2.5);` and `tree.setScale(2.5);`.

   Wait, if we scale it, the physics body needs updating.
   Currently:
   ```javascript
            if (treeType === 'tree_willow') {
                tree.body.setSize(20, 20);
                tree.body.setOffset(40, 180);
                tree.body.x = posX - 10;
                tree.body.y = posY - 20;
            } else {
                tree.body.setSize(20, 20);
                tree.body.setOffset(40, 130);
                tree.body.x = posX - 10;
                tree.body.y = posY - 20;
            }
   ```
   If we use `tree.setScale(2.5)`, the physics body (which is static) will not automatically scale unless we `updateFromGameObject()`. But if we use `updateFromGameObject()`, it resets the size to the FULL display size! So we shouldn't use it.
   Instead, setting `tree.body.setSize(20, 20)` and modifying `x`/`y` directly as it already does `tree.body.x = posX - 10;` is perfectly fine! The physics body doesn't actually care about the sprite scale if we manually set its `x`, `y`, `width`, `height`. So we don't need to change the body logic at all!
