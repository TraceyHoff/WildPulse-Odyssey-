1. We will update `window.createTypeIconTexture` to return a texture key immediately.
2. Inside `window.createTypeIconTexture`, we will define a dictionary of SVG paths for each of the 18 types.
3. We will format the SVG with the theme colors (e.g. `const svgString = '<svg width="16" height="16" ...>' + path + '</svg>'`).
4. We load this SVG as an Image and `drawImage` to the canvas.
5. Then we call `scene.textures.get(key).source[0].update()` (safely checking if it exists) to tell Phaser to update the canvas texture.
6. The nameplate will be updated.
